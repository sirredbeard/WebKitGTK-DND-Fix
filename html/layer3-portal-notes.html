Layer 3: portal / GdkFileList

Unit-level behavior is covered in DropTargetGtk4: when portal MIME types present, filenames come from GdkFileList paths and file:// lines in text/uri-list are ignored for the grant.

Manual check in a Flatpak or portal session:

  1. Run the browser under a portal-using sandbox if available.
  2. Drop a file from the host file manager into the box below.
  3. Expect files.length >= 1 (portal grant works).
  4. There is no safe pure-HTML way to attach a hostile parallel uri-list to a real portal drop; treat code review + Layer 1 as the hostile half.
